# Step 03: Create GitHub Issue + PR

Creates GitHub issue and optional PR with suggested fix.

## Prerequisites

- `gh auth login` (GitHub CLI authenticated)
- Error analysis from `step-02-analyze.md`
- Repository write access

## Verify GitHub Auth

```bash
gh auth status --hostname github.com | head -3
```

Must show "Logged in to github.com as <user>".

## Create GitHub Issue

### Issue Title Format

```
[sre-alert] <error-type>: <one-line-summary>
```

Example:
```
[sre-alert] validation_failed: Profile creation failing for new users
```

### Issue Body Template

```markdown
## SRE Alert

**Detected:** <timestamp>
**Environment:** production
**Severity:** <critical|warning|info>

## Errors Found

- <error-type> (<count> occurrences)

## Log Excerpt

```
<first few log lines>
```

## Root Cause

<Claude analysis summary>

## Suggested Fix

<details>
<summary>Code/Config Change</summary>

```<language>
<suggested-fix>
```

</details>

## Verification

- [ ] Deploy to dev first
- [ ] Test locally
- [ ] Review with team

---
*Generated by SRE Phoenix agent*
```

### Create Issue

```bash
gh issue create \
  --title "[sre-alert] validation_failed: <summary>" \
  --body "$(cat <<'EOF'
## SRE Alert
...
EOF
)" \
  --label "sre-alert" \
  --label "bug" \
  --assignee "@me"
```

## Create PR (Optional)

Only if `--create-pr` flag is set and fix is straightforward.

### PR Title Format

```
fix(sre): <error-type> - <one-line-summary>
```

### PR Body Template

```markdown
## Summary
<Claude analysis>

## Changes
<code/config fix>

## Test Plan
- [ ] Test in dev
- [ ] Verify error pattern resolved
- [ ] Check logs in production after deploy
```

### Create PR

```bash
# Create branch
git checkout -b fix/sre-<error-type>-<timestamp>

# Apply fix
# (Claude-suggested code change)

# Commit and push
git add .
git commit -m "fix(sre): <error-type>: <summary>"
git push -u origin HEAD

# Create PR
gh pr create \
  --title "fix(sre): <error-type>: <summary>" \
  --body "See issue #<issue-number>" \
  --label "sre-alert"
```

## Output Format

```
Issue created: https://github.com/muthuishere/reqsume/issues/<N>
PR created: https://github.com/muthuishere/reqsume/pull/<N>
```

## Guardrails

- **Read-only by default** — use `--create-issue` flag
- **PR requires `--create-pr` flag** (never auto-create PRs)
- **Never force push** — create new commits only
- **Deduplication** — check for existing issue with same error type in last 24h

## Check for Duplicate Issues

```bash
# Check for recent sre-alert issues
gh issue list --label sre-alert --state all --limit 10 | grep "<error-type>"
```

If found → skip issue creation, comment on existing issue instead.

## Success

```
Issue: https://github.com/muthuishere/reqsume/issues/<N>
PR: <link if created>
Analysis: /tmp/sre-phoenix/analyses/<timestamp>.md
```

## Rollback Plan

If fix causes issues:
1. Revert PR
2. Close issue with "false positive" label
3. Document in issue comments
